# Security Policy

## Supported Versions

Only releases on the `master` branch are actively supported with security updates and dependency upgrades.

| Version | Supported          |
|:--------|:------------------:|
| master  | :white_check_mark: |
| < master| :x:                |

## Reporting a Security Vulnerability

If you discover an XSS vulnerability, CSRF flaw, CSP bypass, or frontend security defect:

1. **Do not create public GitHub issues or discussions**.
2. Email maintainer **Tayyab Masood** directly at **tayyabmasood911@gmail.com** with the subject `[SECURITY] Modern React App Vulnerability`.
3. Provide browser context, reproduction steps, and potential exploitation impact.

All reports will be acknowledged within 24 hours.
